Prototype notes

All results come from a mock API in api.js. No file leaves your browser. Try these file names to reach each state:

  • scan-statement.pdf - partial result with a degraded page
  • meeting-markdown.pdf - Markdown only, field extraction failed
  • long-report.pdf - more than 10 pages
  • encrypted-report.pdf and damaged-scan.pdf - encrypted or damaged file
  • image-only.pdf - scanned PDF with no readable text
  • Any file over 40 MB, or a type like .txt, triggers the size and type messages
  • Names containing invoice, receipt, contract or resume return that document type
